# Website 04: FinSuite — Financial Management & Analytics Dashboard Landing

A pixel-accurate frontend recreation of the modern SaaS fintech landing page.

## Route
- `/finance-landing`

## Sections & Key Features
1. **Header Navigation**:
   - FinSuite wallet brand icon
   - Clean links (Home, About Us, Blog, Pages, Pricing)
   - Working Login and Get Started modal triggers
2. **Hero Section**:
   - "Finance Solutions for You" badge in soft lavender
   - High-impact headline with dual-orb icon and electric blue gradient underline scribble on *"Financial"*
   - Interactive 3D floating dashboard mockup with Netflix & Spotify subscription cards, balance breakdown, quick action triggers (Send, Receive, Convert), and animated gradient bar chart with hover tooltips
3. **Social Proof & Metrics Bar**:
   - 4.8 Chrome store, 4.9 Producthunt, 4.8 Trustpilot with crisp 5-star ratings
4. **Comprehensive Analytics Showcase**:
   - Dual-tone headline *"Empower Your Financial Future with us"*
   - Large bento container featuring the prominent lime-green *"My Balance"* dock and vertical gradient metrics bar
   - 2x2 feature checklist with interactive micro-animations
5. **Interactive Modals**:
   - Send Money modal with amount & recipient input
   - Receive Money / QR code modal
   - Currency Converter modal with real-time rate calculator
   - Get Started / Free Trial signup modal
